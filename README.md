# Cucumber BDD API Testing Framework

This workspace contains a Java + Maven + Cucumber + RestAssured API testing framework.

## What is included
- Cucumber BDD feature file
- JUnit runner
- RestAssured step definitions
- Sample API scenario against ReqRes

## Run the tests
1. Open a terminal in this folder.
2. Run:
   mvn test

The test report will be generated in `target/cucumber-reports.html`.
